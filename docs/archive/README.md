# Archived docs

Historical status reports, setup prompts and guides from earlier phases of the
project. They are kept for reference and are no longer maintained. For current
information use the single sources:

- `FEATURES.md` (repo root): what the product does, by module
- `ROADMAP.md` (repo root): what gets built, in what order, and current status
- `CLAUDE.md` (repo root): rules for AI agents working in this repo
- `docs/design.md`: design guidance

Note: the Firebase and Supabase guides in this folder describe the legacy root
Next.js app, which is being merged into `ops-hub`.
